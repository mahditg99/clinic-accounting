# نبض کلینیک — نرم‌افزار حسابداری کلینیک آذران طب

نسخهٔ انگلیسی: [README.md](README.md)

نرم‌افزار حسابداری **فارسی و راست‌به‌چپ** برای کلینیک‌های کوچک: صدور فاکتور،
پروندهٔ بیماران، انبار و محصولات، هزینه‌ها و گزارش‌های مالی — به‌همراه نسخهٔ
وب که روی همان دیتابیس می‌چرخد. طوری ساخته شده که روی **ویندوز ۷** با
**پایتون ۳.۸** اجرا شود، به یک `exe` قابل‌حمل تبدیل شود و با **لایسنس
سخت‌افزاری** عرضه گردد.

- زبان رابط: فارسی، راست‌به‌چپ، ارقام فارسی، تقویم جلالی.
- دسکتاپ: پایتون ۳.۸ + Qt 5.15 (PyQt5 یا PySide2، خودکار تشخیص داده می‌شود) + SQLite.
- وب: FastAPI + Jinja2 روی **همان** فایل دیتابیس.
- بدون QtWebEngine، بدون ORM، بدون هیچ پکیج باینری رمزنگاری.

---

## چه کارهایی می‌کند

سیزده صفحه در نسخهٔ دسکتاپ که عیناً در نسخهٔ وب هم هست:

| بخش | صفحه‌ها |
|---|---|
| کار روزانه | داشبورد · فاکتور جدید · آرشیو فاکتورها · پرونده‌ها · فهرست محصولات |
| گزارش‌ها | گزارش روزانه · درآمد / هزینه · هزینه‌ها · گزارش‌های مالی · گزارش پزشکان · فروش محصولات |
| مدیریت | فهرست پزشکان · تنظیمات |

نکته‌های مهم:

- **فاکتور** — چند قلم با قیمت خرید/فروش و تخفیف، چند روش پرداخت در یک
  فاکتور، پرداخت ناقص، کسر خودکار موجودی، ابطال با برگرداندن انبار، چاپ A4.
- **پرونده‌ها** — جستجوی زنده، تاریخچهٔ فاکتور هر بیمار، حذف امن (بیماری که
  فاکتور دارد به‌جای حذف، غیرفعال می‌شود).
- **انبار** — قیمت خرید و فروش، موجودی، هشدار کمبود، شارژ موجودی، گزارش فروش
  هر محصول با سود.
- **درآمد و هزینه** — دسته‌بندی هزینه‌ها، گزارش ارجاع پزشکان، خلاصهٔ مالی
  ماهانه/سالانه (دریافتی، هزینه، سود خالص).
- **چاپ** — همان HTML که نسخهٔ وب چاپ می‌کند، با پیش‌نمایش Qt.
- **همه‌چیز فارسی** — تقویم جلالی روی هر فیلد تاریخ، ارقام فارسی در هر عدد،
  جدول‌های راست‌به‌چپ با مرتب‌سازی با کلیک روی سرستون، و فونت **وزیرمتن**
  بسته‌بندی‌شده داخل برنامه تا روی یک ویندوز ۷ خام هم دقیقاً همان‌طور دیده شود.

## پیش‌نیازها

- ویندوز ۷ SP1 یا جدیدتر (۳۲ یا ۶۴ بیت). روی لینوکس و مکس هم اجرا می‌شود؛
  فقط بررسی لایسنس مخصوص ویندوز است و در اجرای از سورس اصلاً فعال نمی‌شود.
- **پایتون ۳.۸.x** — دقیقاً. نسخهٔ ۳.۹ به بعد روی ویندوز ۷ کار نمی‌کند.
- اتصال Qt 5.15: `PySide2==5.15.2.1` (ترجیحاً) یا `PyQt5==5.15.x`.
- `jdatetime` برای تبدیل تاریخ جلالی.
- اختیاری (نسخهٔ وب): `fastapi`، `uvicorn`، `jinja2`، `python-multipart`.

## شروع سریع

```bat
cd azaran_teb
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

ورود با **admin / admin** (از نوار بالا قابل تغییر است).

دیتابیس SQLite در اولین اجرا با نام `azaran_teb.db` **کنار فایل exe** ساخته
می‌شود (یا کنار `main.py` وقتی از سورس اجرا می‌کنید)؛ به همین دلیل کل پوشه
قابل‌حمل است.

نسخهٔ مرورگر، روی همان دیتابیس:

```bat
python -m uvicorn webapp.main:app --reload --port 8000
```

سپس نشانی <http://127.0.0.1:8000> را باز کنید.

## معماری و تصمیم‌های فنی

**یک لایهٔ داده، دو رابط.** همهٔ کوئری‌ها در `app/models.py` است و هم صفحه‌های
دسکتاپ و هم قالب‌های FastAPI همان را صدا می‌زنند؛ بنابراین هر قابلیت یک‌بار
پیاده می‌شود و دو رابط از هم دور نمی‌افتند.

**رابط وب، مرجع طراحی است.** تک‌تک صفحه‌های دسکتاپ برای هم‌خوانی پیکسل‌به‌پیکسل
با `webapp/templates/*.html` و `static/style.css` بازسازی شده‌اند: همان رنگ‌ها،
همان کارت‌ها، همان نوار ECG.

**راست‌به‌چپ صریح است، نه ارثی.** Qt پرچم‌های `AlignLeft`/`AlignRight` را
*نسبت به جهتِ ویجت* معنا می‌کند؛ پس در جدولِ RTL، `AlignRight` متن را در
**چپِ** بصری می‌کشد. به همین دلیل `app/ui/fields.py` برای راست‌چین‌کردن
سرستون‌ها و سلول‌ها `AlignLeft` می‌خواهد. `QLabel` چندخطی باز فرق دارد: رشتهٔ
فقط-عددی (مثل تاریخ جلالی) پاراگرافش LTR تشخیص داده می‌شود و به چپ می‌رود،
پس آن مقادیر با نشانگر U+200F شروع می‌شوند. هر دو رفتار با پروب پیکسلی قفل
شده‌اند (`_rtlprobe.py` و `_liclayout.py`).

**صفحه‌های پر‌مقیاس روی ویندوز ۷.** Qt 5.15 ضریب مقیاس خودکار را به عدد صحیح
گرد می‌کند؛ برای همین `setup_scaling()` مقدار `QT_FONT_DPI=96` را تثبیت می‌کند
و `QT_SCALE_FACTOR = dpi/96` را یکدست اعمال می‌کند — و حتماً **قبل** از ساخته
شدن `QApplication`. این همان چیزی است که باعث می‌شود روی لپ‌تاپ ۱۲۵٪ یا ۱۵۰٪
متن و آیکون بریده نشود.

**جدول‌های بزرگ سریع می‌مانند.** جدول‌هایی که در هر ردیف دکمهٔ عملیات دارند،
این دکمه‌ها را فقط برای ردیف‌های قابل‌مشاهده می‌سازند
(`set_row_widget_factory`) و با اسکرول بازیافت می‌کنند؛ محاسبهٔ اندازه هم با
یک `schedule_fit()` تجمیع‌شده انجام می‌شود. روی آرشیو ۵۸۸ فاکتوری: باز شدن
صفحه از **۵۴٫۷ ثانیه به ۱٫۱ ثانیه** رسید. مرتب‌سازی هم امن است، چون Qt ویجت‌های
ردیف را با خودش جابه‌جا می‌کند.

## لایسنس سخت‌افزاری

نسخهٔ exe فقط روی دستگاهی که فروشنده مجازش کرده اجرا می‌شود.

- **کد سخت‌افزاری** — هش SHA-256 از `MachineGuid` ویندوز، نمایش به شکل ۲۰
  نویسه در چهار گروه: `ABCDE-FGHIJ-KLMNP-QRSTU`. عوض‌کردن هارد/رم/کارت شبکه
  آن را تغییر نمی‌دهد؛ نصب مجدد ویندوز یا کپی‌کردن پوشه روی دستگاه دیگر
  تغییرش می‌دهد.
- **فایل لایسنس** — `license.key` کنار exe، با شکل
  `AZARAN1.<payload>.<signature>`؛ payload یک JSON است
  (`v, hw, name, issued, expires|null`) و امضا **RSA-2048 / PKCS#1 v1.5 /
  SHA-256** روی همان بایت‌های payload است.
- **کلیدها** — کلید *عمومی* داخل `app/license.py` است و کلید *خصوصی* در
  `keys/issuer_private.json` که در `.gitignore` قرار دارد و هرگز نباید منتشر
  یا همراه برنامه ارسال شود. `rsa_lite.py` روی `int` و `pow` خود پایتون نوشته
  شده تا ساخت exe به هیچ ویل باینری رمزنگاری وابسته نباشد.
- **رفتار** — یک‌بار در شروع اجرا بررسی می‌شود، و فقط در نسخهٔ exe
  (`sys.frozen`). معتبر باشد: مستقیم صفحهٔ ورود. نبود / مربوط به دستگاه دیگر
  باشد / امضا درست نخورد / منقضی شده باشد: پنجرهٔ «فعال‌سازی نرم‌افزار» با
  دلیل فارسی، کد سخت‌افزاری با دکمهٔ کپی، و «انتخاب فایل لایسنس…» که فایل را
  کنار exe می‌گذارد و وارد برنامه می‌شود. گزینهٔ **«مجوز نرم‌افزار»** پایین منوی
  سمت راست همیشه جزئیات کامل را نشان می‌دهد و در ۱۵ روز پایانی یک یادآوری
  یک‌باره نمایش داده می‌شود.
- **نگهبان ساعت** — بیشترین تاریخی که برنامه دیده در جدول `settings` می‌ماند؛
  اگر ساعت ویندوز بیشتر از دو روز عقب‌تر برود، لایسنس رد می‌شود تا نتوان با
  عوض‌کردن تاریخ، لایسنس منقضی را زنده کرد. آن دو روز تلورانس گذاشته شده تا
  تمام‌شدن باتری CMOS کسی را قفل نکند.
- **صدور لایسنس**

  ```bat
  python tools\license_issuer.py                 :: پنجرهٔ گرافیکی (صدور / کلیدها / راهنما)
  python tools\license_issuer.py --print-hwid
  python tools\license_issuer.py --hw <CODE> --name "کلینیک آذر" --expires 1407-06-31 --out license.key
  python tools\license_issuer.py --verify license.key
  ```

  مراحل کامل در [LICENSE-HOWTO.md](LICENSE-HOWTO.md).

> **دو نکته را صریح بگوییم.** اگر `keys/issuer_private.json` گم شود، تا وقتی
> جفت‌کلید تازه‌ای نسازید، کلید عمومی داخل برنامه را عوض نکنید و exe را
> بازسازی نکنید، نمی‌توانید لایسنس تازه بدهید — و همهٔ لایسنس‌های قبلی هم
> بی‌اعتبار می‌شوند. هیچ بررسی سمت کلاینتی در برابر کسی که فایل‌های داخل
> PyInstaller را دستکاری کند مقاوم نیست؛ این طرح کپی‌کردن پوشه روی دستگاه
> دیگر را مسدود می‌کند که مشکل واقعی همین بازار است، نه DRM.

## دادهٔ نمونه

```bat
python _seed_demo.py
```

یک‌بار و بی‌خطر تکرار (با پرچم `settings.demo_seeded`). ۸ پزشک، ۲۵۰ بیمار،
۶۶ محصول، حدود ۵۸۵ فاکتور و ۲۵۰ هزینه در ۱۳ ماه گذشته با نام‌های واقعی فارسی
را وارد می‌کند تا رفتار اسکرول، مرتب‌سازی و گزارش‌ها با حجم بالا سنجیده شود.

## تست‌ها و پروب‌ها

فریمورک تست ندارد؛ هر اسکریپت در صورت خطا کد خروج غیرصفر برمی‌گرداند و خلاصه
چاپ می‌کند.

| اسکریپت | چه چیزی را ثابت می‌کند |
|---|---|
| `smoke_ui.py` | تک‌تک صفحه‌ها بدون استثنا باز، تازه و تغییراندازه می‌شوند |
| `_verifyfixes.py` | ۸۰ بررسی روی همهٔ باگ‌های گزارش‌شده (فونت، RTL، عرض ستون، لایسنس، انتخاب بیمار) |
| `_licenseprobe.py` | ۱۰۷ بررسی: RSA، فرمت توکن، رد امضا/دستگاه دیگر/انقضا/ساعت، CLI ابزار صدور |
| `_liclayout.py` | پنجره‌های لایسنس: لبهٔ راست، بدون بریدگی، کد وسط‌چین |
| `_issuelayout.py` | پنجرهٔ ابزار صدور: اعتبارسنجی، پیش‌تنظیم‌ها، مسیر صدور |
| `_rtlprobe.py` | پیکسل‌سنجیِ تک‌تک سرستون‌ها و سلول‌ها → باید صفر مورد چپ‌چسب باشد |
| `_colprobe.py` / `_btnprobe.py` | عرض همهٔ ستون‌ها با دادهٔ واقعی / جا‌شدن دکمه‌های عملیات |
| `_lazyprobe.py` | ویجت‌های تنبل محدود می‌مانند و با مرتب‌سازی و اسکرول به ردیف درست می‌چسبند |
| `_pickprobe.py` | جریان‌های پنجرهٔ انتخاب بیمار |
| `_perfprobe.py` | زمان باز شدن صفحه، اسکرول و تغییر اندازه روی دیتابیس نمونه |
| `_launchtest.ps1` | اجرای exe در یک کپی موقت: بدون لایسنس، لایسنس بیگانه، لایسنس معتبر |

```bat
python smoke_ui.py
python _verifyfixes.py
python _licenseprobe.py
powershell -File _launchtest.ps1
```

## ساخت exe

```bat
pip install pyinstaller
pyinstaller --noconfirm AzaranTeb.spec
```

خروجی `dist\AzaranTeb\AzaranTeb.exe` به شکل **پوشه‌ای** (onedir) است: شروع
سریع‌تر، سازگاری بهتر با آنتی‌ویروس ویندوز ۷، و دیتابیس و پوشهٔ backups و
فایل license.key همه کنار exe می‌مانند؛ پس کل پوشه قابل‌حمل است. **کل** پوشهٔ
`AzaranTeb` را ببرید — و `keys\`، `tools\` یا هیچ `license.key` را همراهش
**نگذارید**.

نکتهٔ ویندوز ۷: Qt 5.15 آخرین نسخهٔ سازگار با هفت است، پس روی پایتون ۳.۸ و
PyQt5/PySide2 5.15.x بمانید، QtWebEngine اضافه نکنید، و روی سیستم‌های خام به
نیاز به runtime ویژوال‌سی ++ ۲۰۱۵-۲۰۱۹ انتظار داشته باشید.
